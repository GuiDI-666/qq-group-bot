# QQ 群管机器人

> 代码仓库：https://github.com/GuiDI-666/qq-group-bot （公开）
> 发布新版本用 `python deploy/release.py v1.x.x "说明"`，会自动提交并推送。

一套开箱即用的 QQ 群管理机器人，基于 **NoneBot2 + OneBot v11（NapCat 协议端）** 实现，**不依赖任何智能体平台**，自己电脑/服务器上跑起来就是一个独立的群管服务。

## 功能一览

| 分类 | 能力 |
|---|---|
| 入群审批 | 自动通过 QQ 等级达标的入群申请（门槛可设），不达标按策略忽略/拒绝 |
| 广告拦截 | 按正则规则识别广告/引流内容，撤回 + 禁言；管理员发言仅提示、不误伤 |
| 违禁词 | 自定义违禁词表，命中即撤回并禁言 |
| 成员管理 | 禁言 / 解除禁言 / 踢出，支持 @ 或直接写 QQ 号 |
| 黑名单 | 拉黑 / 解除拉黑 / 查看名单，拉黑自动踢出且拒绝再次入群 |
| 欢迎语 | 入群欢迎、退群提示文案可热改 |
| 潜水名单 | `未发言` 命令按 30/60/90 天拉取未发言成员，结果可合并转发并落盘存档 |
| 菜单 / 存活 | `菜单` 查看指令，`存活` 检查在线状态与运行时长 |
| 运行保障 | 看门狗守护进程 + 登录失效自动重登 + 睡眠唤醒自愈 + 开机自启 |

## 安全设计（重要）

- **只在自己的群里干活**：`managed_groups` 白名单之外的群，机器人完全不响应（不回复、不处理）
- **机器人不是管理员的群，同样静默**：避免在无权限的群里刷屏
- **管理群名单类命令只能私聊使用**：群内发无效，防止普通成员误操作
- **权限分级**：超级管理员 / 群主 / 群管理员 才能执行管理命令，普通成员发指令无任何反馈
- **不误伤管理员**：管理员触发广告规则只提示"发言不规范"，不撤回不禁言

## 快速开始

1. 安装 Python 3.10+（脚本会自动装依赖）
2. 复制 `部署配置.example.json` → 改名为 `部署配置.json`，填入：机器人 QQ 号、超级管理员 QQ 号、NapCat 目录
3. 双击 `一键部署.bat` —— 自动检查环境、安装依赖、下载配置协议端、部署机器人、跑自检
4. 双击 `启动机器人.bat` —— 进入看门狗守护模式常驻运行
5. 首次登录需手机 QQ 扫码（协议端会生成二维码图片），之后可免扫码快速登录

> 仓库**不含任何真实账号信息**：所有个人配置都走 `*.example` 模板（`部署配置.json`、`qq-group-bot/.env`、`qq-group-bot/config.json` 均已被 `.gitignore` 排除）。

## 常用指令

| 场景 | 指令 |
|---|---|
| 禁言 / 解禁 / 踢出 | `禁言 @某人 30`、`禁言 1234567 30`、`解除禁言 @某人`、`踢出 @某人` |
| 黑名单 | `拉黑 @某人`、`解除拉黑 1234567`、`黑名单` |
| 潜水名单 | `未发言`、`未发言 60`、`未发言 90`（私聊可加群号：`未发言 <群号> 30`） |
| 热设置 | `设置等级 30`、`添加广告词 xxx`、`设置欢迎 xxx`、`设置退群 xxx` |
| 管理群（仅私聊） | `添加管理群 <群号>`、`移除管理群 <群号>`、`管理群列表` |
| 状态 | `菜单`、`存活`、`ping` |

> 命令支持裸写（不带前缀）或 `/指令` 两种写法。

## 注意事项

- 使用第三方协议端（NapCat）属于非官方方案，存在账号风控风险，建议使用小号并控制操作频率
- 全局配置为单份，跨群生效（白名单机制用于限定生效范围）
- 睡眠/休眠会中断进程与网络，长时间挂机请关闭睡眠；看门狗已支持唤醒后自愈
